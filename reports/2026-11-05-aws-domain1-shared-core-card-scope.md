# 领域1共享核心卡数量与覆盖分析

2026-11-05。按用户最新要求，全库以约300张共享短卡为设计目标，四领域引用同一套知识卡。

**本轮筛出60个跨题复用的核心卡设计候选，但它们尚不足以覆盖领域1全部必要考点。因此60是核心候选规模，不能写成领域1最终只需60张。**

| 本轮结果 | 数量与含义 |
| --- | --- |
| 安全知识核心候选 | 47个，暂归领域1导航 |
| 其他领域通用规则候选 | 13个，由领域1共同引用 |
| 去重后核心候选合计 | **60个**，不按四领域重复累加 |
| 全部考点是否已由该卡组覆盖 | **否，已找到具体反例** |
| 领域1最终所需卡数 | **尚不能冻结**，须解决真实缺口后确定 |

这里的60个是中文设计原型，不是已完成正式卡。上表47个安全核心候选与此前领域1已制作47张只是数值巧合；本轮60个原型也不是既有62张接受库存的缩减导出。它们未建立逐UID等价关系，不能用相减算出“还要做几张”。本轮没有新增、撤销或修改正式接受卡。

**本轮如何减少数量。** 直接复用上一轮296个细节候选、既有考点和原题，按共同判断与因果筛选，而非重新提取全库。三组得到19、20、23个核心原型；再合并“资源操作与KMS授权分别满足”和“静态加密不能代替TLS”两组跨组重复，得到60个。每个原型列出至少3道实际题目的局部用途，不因主题相同就挂题号。

一个规则可以参与多道题，几张短卡共同解释一族题；单卡仍保留一个主要判断及必要原因。领域分类与知识卡归属是导航安排，13个通用规则供其他领域继续共享，不重复制作正文。这一暂分类没有修改原始考试领域总表。

**覆盖检查已确认以下真实缺口。** 这些不是为了讲完弱干扰项而扩展的背景知识，而是正确方案满足题干要求所需的正向机制。

| 原题 | 当前卡组仍缺少什么 | 为什么现有规则不够 |
| --- | --- | --- |
| Q325、Q1011 | Cognito身份池把已认证用户接到适当IAM角色并取得AWS临时凭证 | 已教“用户池负责登录，JWT不是AWS密钥”，但还没教从登录到S3访问凭证的桥接步骤 |
| Q393 | 音频转文字并在转录输出中去除PII的能力 | Macie内容发现、事件通知、行列授权均不能产生所需脱敏文字 |
| Q833 | 使用输入转换给不同校验步骤只交付所需字段 | 消息过滤决定是否投递；运行角色限制资源操作，两者都不会自动裁掉消息中的其他字段 |

这些缺口优先检查能否由全库其他核心卡承担，或在保持一个回忆任务的前提下调整已有原型；无法由现有规则推出时，仍保留明确义务。不能把反例数直接当新增卡数，也不能仅把新知识放进题解便算卡片覆盖完成。

**考点资料完整与卡片支撑充分分别记录。**

- 原领域1范围仍为371题、622个原判断引用；本轮296个细节候选全部有去向，原30个待定目标保留。没有因筛核心卡删除原题或考点。
- 本轮原始去向为73条规则绑定、40条组合应用、183条尚未可靠归并的候选。183条包含重复、需跨组复用、题源问题和真实缺口，绝不等于183张必增卡；164条缺口记录也不能直接折成卡数。
- 622条判断的规划引用保持完整，并统一标记为未完成语义覆盖验证；完整引用不是371题全部可由卡组作答的证明。
- 既有正式卡逐题账本仍是17题充分、25题部分、14题需重核、315题未评估。它不自动转成新核心原型的覆盖结果，学习者实际作答效果也尚未测量。
- Q618等还存在题源限定不清的问题。这类题继续保留并单列，不能靠加一张卡伪装闭合。

**当前可作出的决定。** 将这60个候选作为高复用核心层，停止按领域细节无限扩卡。接下来只核查仍会妨碍解释正确方案的真实缺口，优先跨领域复用与必要的规则调整，再确定领域1完整卡数。全库约300张仍是设计目标，是否足够必须用完整题目回测证明。

独立审查定向核对5张原型的15个代表用途，认可两组规划去重，并确认上述三个未覆盖反例。它没有给出全卡事实、371题全覆盖或最少卡数的PASS。原始审查和修正谱系均保留。
