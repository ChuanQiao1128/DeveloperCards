# 领域1：逐题素材、共享判题规则与制卡衔接计划

日期：2026-11-04 · v1.0 · 本轮为计划交付，尚未启动素材生成或制卡。

目标：基于已有蓝图，把领域1各题需要的判断组织成可复用的教学素材，使后续卡片能明确解释“题干条件为什么导向这个判断”。已有考点、条件和需求审查直接复用，不重复提取，不另写371篇长解析。

## 一、先生成全域逐题素材引用表

使用已验收的domain_index.py及其manifest，在本地导出371条记录：题号／questionRef、本域任务标签、已有objectiveId、needRefs、conditionRefs、变式及异常来源引用。记录当前源版本。

原题全文、全部选项、既有判断和条件不重新写作，制卡需要时按引用读取完整内容。素材表中的新增部分只有：该题引用哪些共享判题规则、哪些本题差异仍需保留、当前就绪／待核／跨域引用状态。

通过条件：371题精确集合一致、622候选判断有来源与去向、无重复实体、跨任务引用一致；源蓝图与分类文件哈希不变。此时只表示材料齐全，不宣称技术规则已经核验。

## 二、按小组确认本域教学范围和共享关系

优先审查103个在本域关联多题的目标，再结合跨域可复用目标和必要基础。关联数仅用于寻找候选，不直接决定价值。

每个被处理目标只登记新的教学处置：

- 本域核心判断；
- 本域需要的先修，或已有先修引用；
- 跨域知识引用；
- 可与既有目标共用同一规则；
- 暂不需要独立新增教学，附具体理由；
- 证据或归属仍待确认。

559是题目标签带入的导航集合。跨领域题包含的非安全判断继续回链相应领域，不强行在领域1讲完；原目标和必要判断保留去向，不从全库删除。这里确认的是暂定教学归属，既有原题分类不改。

相同机制和可迁移判断规则可以共享。协议、身份、资源范围、时效或其他条件改变结论时，保留条件分支；同服务名、同答案字母或表面相似不足以归并。

默认沿用现有目标作为候选单元。只为实际提出的新归并保存稀疏决定及原目标ID；不为559目标再建一套平行知识库。

## 三、按共享单元补成有依据的判题规则

全域引用表可一次导出；教学归组、取证、规则完善和审查按小组连续推进，不要求先研究完整个领域才交付可用素材。

每条规则只写完成教学需要的内容：

| 字段 | 内容 |
| --- | --- |
| 触发条件 | 对应哪些既有条件；哪些题适用，哪些限制只属于某个变式 |
| 机制依据 | 必须理解的AWS机制，绑定官方原句、URL、定位和版本 |
| 判断动作 | 根据这个机制可以选择、排除或检查什么 |
| 关键边界 | 最容易混淆且会改变选择的一项差异；无必要时不硬加 |
| 具体支持 | 对应哪些needRefs、本题还缺哪些判断、必要先修怎样承接 |

一个官方片段可以支持多个适用场景，但不能把某题限制传播成整个组的共同前提。每条就绪规则都必须明确其适用needRefs及条件。

按机制共享本地官方检索和已核对证据；缺证据时再定向查官方页面。印刷答案、社区投票和CSV建议答案不作技术依据。含答案的待核文字只保留来源引用，不送入规则或卡片知识输入。

没有查到的必要事实保留具体缺口和查证记录，不能用泛泛“如何判断”包装为就绪规则。真实源歧义继续单列，不强行给唯一答案。

## 四、先用两个不同结构的小组校准

第一组从任务1.1的已有目标开始，暂选：

| 既有目标 | 校准用途 |
| --- | --- |
| obj-b06-g24 | 运行身份、权限策略、信任策略分别绑定谁；来源Q100/Q179/Q371/Q550/Q640 |
| obj-b06-g25 | Lambda执行身份与KMS密钥策略的联合授权边界；来源Q550/Q640 |
| obj-b06-g26 | 检查组合目标相对前两者是否新增必要的整合判断；来源Q550/Q640 |

三个目标不预定三张卡。若组合目标只重复前两者，作为练习或变式引用；若确有额外判断，才保留独立应用任务。源scope中“不将S3访问变为所有变式前提”等边界完整带入。

第一组能检验授权机制共享和基础／组合的划分，代表性有限。扩量前再选任务1.2或1.3中一个条件结构不同的小组，例如来源限制与网络可达性辨析，检验相同素材格式是否仍能表达条件变化。

两个小组都只引用原有考点和全部相关原题，不重新抽题。审查输入包含完整当前goal、scope、conditionRefs、variants、组合引用、相关原题与全部选项以及实际官方依据，避免只看标题而误判遗漏。

## 五、批次执行、Review与修正

沿用单个主作者和既有模型通道。脚本负责构包、检索、ID／来源绑定、计数、断点和渲染；模型只处理新的语义处置与判题规则。独立Reviewer使用fork_turns:none的最小冻结输入。

先以少量可界定目标成组；一般每批3–5个目标，实际按完整输入字节和复杂度调整。超限缩批，不裁掉条件或必要原文。规则按单元输出，差异按题目引用，不复制整篇解析。

同次Review核对：

1. 条件→机制→判断是否成立，官方原句是否真正支持该适用范围。
2. 每个关联题得到哪一步帮助，是否仍缺必要判断；不能只因主题相同认定支持。
3. 共享是否丢条件，是否给弱干扰项或先修增加无关课程。
4. 素材粒度是否能转成一个主要回忆任务，是否有堆砌或过碎拆分。
5. 新主归／归并是否有理由，原目标及判断是否保留可追溯去向。

仅修失败规则及受影响关系。每个finding最多2次自动修复并继承历史；已闭合问题不因读到旧FAIL重新开启。达到现有限额保存真实进度，不清零时钟、token或问题计数继续派发。

## 六、素材就绪与正式制卡衔接

为371题及622候选判断分别登记：就绪规则引用、待核实、跨域引用、无需新增教学及理由等去向。结构有去向与技术规则就绪分别统计；不能只凭一张引用表宣告材料全部可制卡。

现有15张接受卡的逐目标绑定仍未知。某组正式制卡前，只检查其中可能相关的既有卡，按实际正文和当前标准建立绑定；空绑定不能当作未出卡，也不能把已有卡正文替代官方事实。

素材直接用于后续卡片，不再另写一遍通用知识报告：

- 答：本卡的动作或结论。
- 考点：把题干的决定条件接到机制与判断，明确为什么这个知识能帮助选择或排除；不重复答案。
- 易错提醒：真正会改变选择的竞争边界，没有必要时省略。

每张普通卡仍只训练一个主要判断及原因。题号、答案字母和逐选项映射留私有材料，公开卡片教可迁移方法。实际卡片产生后，才能正式确认direct_test／prerequisite／partial及整题支撑；学会一个共享单元，不自动计为整道综合题已解决。

## 产物与完成标准

执行时在独立阶段目录保存以下产物，源五文件和分类表不覆盖：

1. 领域1逐题素材引用表：371条原题记录，关联622候选判断及既有目标。
2. 稀疏教学处置和共享规则：原目标引用、暂定归属、规则正文、适用条件、needRefs和先修承接。
3. 官方证据与未决清单：共享证据只存一份，保留各规则适用范围和真实缺口。
4. 验收记录及可读MD：唯一题目集合、判断去向、已就绪／待核数量、实际共享题数和完整Review谱系。

阶段完成时，371题及622判断全部有具体素材去向，已提出的新归并和就绪规则均有本轮有效审查，确认缺口闭合或诚实列明待核。只要仍有必要事实未闭合，就不能宣称领域1全部素材已就绪。559目标中哪些真正服务本域、最终多少共享单元／卡片，以审校结果为准。

现阶段验收的是制卡素材，不是已有卡片完全支撑371题，也不是实际记忆或提分。领域外判断和来源疑点不为凑闭合而省略。
